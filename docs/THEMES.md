# 🎨 Cybercore theme system

The desktop site and terminal UI share four named palette concepts. Android will use the same tokens while adapting controls to native Material components.

| Theme | Accent | Secondary | Character |
| --- | --- | --- | --- |
| Neon Cyan | Electric cyan | Hot pink | Cybercore signature |
| Plasma | Violet | Ion teal | Deep space |
| Ember | Warm orange | Magenta | Heat and motion |
| Biohazard | Acid green | Bio teal | High-contrast field mode |

Theme selection is local presentation state. It never changes note content or the vault format. Sites respect reduced-motion settings and maintain readable contrast; terminal themes avoid relying on color alone to signal selection.
